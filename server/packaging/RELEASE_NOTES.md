## 本版新增（1.0.0-rc.8）

- **长任务不再被半路掐掉**：超时改成「多久没有进展」——模型在出字、工具在执行都算在干活，跑命令期间不计时；
  另有单轮总时长上限（默认 30 分钟）兜底。两个都在「设置 → 系统 → 运行时」，改完即时生效
- 卡死的工具不再拖住整轮：超时后最多再等 2 秒就结束这一轮

## 1.0.0-rc.7

- **飞书里收到消息会先贴一个「敲键盘」表情**，表示她在处理，回复发出后撤掉（和 OpenClaw 时一样）。
  需要在飞书开放平台给应用加权限 `im:message.reactions:write_only` 并发布新版本；没开权限就不贴，不影响聊天

## 1.0.0-rc.6

- **语音服务商可选，不再只能用百度**（设置 → 语音 → 语音服务）：识别、合成各自选一家——
  百度、OpenAI 兼容接口（OpenAI、硅基流动、本机 VoiceStudio 等）、MiniMax（支持复刻音色）
- 每个 agent 可以单独选合成服务商和音色（Agents → 基本），可试听；那家出错时自动退回默认服务商

## 1.0.0-rc.5

- **传话**：在飞书 / QQ / 网页里说「跟家里说一声我晚点回」，她会在家里的设备上播出来，不管你在不在家（语音推送设成「从不播放」时除外）
- **长回复念一段口语摘要**：IM / 网页回复太长时，由便宜模型压成一段适合朗读的话再播，长度跟着 agent 的「语音回复字数」走；
  以前是固定截断 200 字
- 对设备说「我要出门了」会正确记为不在家；免手模式下的环境声不再把状态改回在家

## 1.0.0-rc.4

- **语音播报完全交给系统**：agent 不再有「说话」工具。它发给你的所有消息（飞书 / QQ 私聊和网页聊天的回复、定时任务、heartbeat、
  后台任务结果、提醒）都由系统按「设置 → 语音」决定要不要同时在设备上播
- **对设备说话、摇一摇、触摸、按 ROLE 键都会自动记为在家**
- **多角色共用一台设备改为可选**（设置 → 语音）：默认恢复「先留言，切到那个角色再播」；
  也可以选「立即播放，临时显示该角色」（rc.3 的做法）
- 配置过模型后，设置页不再显示「快速开始」

## 1.0.0-rc.3

- **语音推送对 agent 透明**：在家播、不在家不播，也可以在「设置 → 语音」改成总是播 / 从不播。
  rc.2 的「不在家改发 IM」「留言等切换角色」取消；IM 账号里的「同时播语音」并入这个全局设置
- **多个角色共用一台设备**：某个角色说的话用它的音色播，设备播放时临时换成它的图片，播完换回（需更新设备代码）
- **管理界面改版**：深色青底配色（参考 Hermes Agent），侧边栏分组和图标，总览加数字卡片，可切换浅色 / 跟随系统；
  精简了各页的说明文字

## 1.0.0-rc.2

- **说给你听的话由系统统一决定怎么送**，不再靠提示词劝她：
  - 你不在家时，她主动说的话（定时任务、heartbeat、`speak`、提醒、后台任务结果）改发到你最近用的飞书 / QQ 私聊；
    没配 IM 就先留着，你回家时在设备上播
  - **只用当前角色的形象和声音说话**：设备显示小澪时，神乐要说的话先留着，切到神乐时（问候之后）再播。「设备」页能看到和清空留言

## 1.0.0-rc.1（正式版候选）

新服务端合入主线后的第一个候选版。请日常使用一段时间，有问题随时反馈；没有新问题就转为 1.0.0 正式版。

- **托盘真正不弹窗口了**：开始菜单、开机自启改用 `kagura-tray.exe`（同一个程序，标成图形界面程序），启动根本不开控制台；
  启动失败会弹框说明原因；已经在运行时再点开始菜单就打开管理页。排障时可以用「Kagura 服务端（显示窗口）」
- **管理页一键更新**（设置 → 更新）：下载新版、校验、安装、自动重启。Windows 安装版会弹一次管理员确认；deb 版给出一条安装命令
- **导出 / 导入**（设置 → 导出 / 导入）：勾选设置、各 agent 的人设 / 记忆 / 技能 / 会话、技能、扩展、扩展包、IM 渠道、定时任务、设备图片，
  打成一个 .zip；换电脑或分享给别人时一键导入。默认不带密钥，被替换的内容先备份
- **安全**：管理接口挡住网页借浏览器调用（跨站请求伪造）；新设备要在「设备」页批准后才能让她执行命令、装扩展（第一台自动批准）
- 设备页直接切换角色；有新版本时总览页和 IM `/status` 提示
- 百度识别可选「极速版」（设置 → 语音与设备）；她会把语音识别里的同音错字按上下文理解

**从 beta 升级**：直接装新版安装包，数据和设置都保留。不止一台设备的，第一台以外的要去「设备」页点「批准」。

## 下载哪个

| 系统 | 文件 | 说明 |
|---|---|---|
| Windows 10/11（64 位） | `Kagura-Setup-*.exe` | 安装包：自动加防火墙规则，可选开机自启，装完打开管理界面 |
| Linux（Debian / Ubuntu） | `kagura_*_amd64.deb` | `sudo apt install ./kagura_*.deb`，然后 `systemctl --user enable --now kagura` |
| Linux（其它发行版） | `Kagura-*-x86_64.AppImage` | `chmod +x` 后双击或在终端运行 |
| CoreS3 设备固件 | `kagura-device-*.zip` | 按包里的「烧录说明.md」上传到设备 |

`SHA256SUMS` 是校验和。安装包暂未签名，Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」。

## 第一次用

1. 装好后打开 **http://127.0.0.1:5000/admin**（只限本机），在「设置 → 首次设置」填你自己的模型服务商、模型名和 API Key（不预设任何模型），再填百度语音 Key。
2. 设备开机后会在局域网自动找到服务端。
3. 从旧版迁移：`kagura migrate <voice_server.py 所在目录>`；从 OpenClaw 迁移：管理界面「定时任务 → 从 OpenClaw 导入」。
4. 旧的 mosquitto 要停掉：新服务端自带 MQTT（端口 1883）。

数据在 `%APPDATA%\Kagura`（Windows）或 `~/.local/share/kagura`（Linux），卸载不会删除。
