## 本版新增（1.0.0-rc.36）

- **飞书 / 网页聊天的长回复，设备几秒内就开口**：以前要等整条回复写完，再找便宜模型压成口语（20 秒压不完就截断着念）。
  现在她在回复最前面先写一段念给你听的口语版，一写完就推给设备，正文还在继续写；聊天里看不到这段
- **主动说的话边合成边播**：一段话不止一句时，第一句合成好就开始播，不用等整段合成完
- **她没写朗读版时的兜底更好**：「设置 → 模型」可以单独选「朗读兜底模型」，按它自己的「思考」设置跑（开着思考时多给些时间，60 秒）
- **服务端退出一定留痕**：日志每行立刻落盘，每次退出都记一行原因；日志末尾没有 `[exit]` 那行 = 被强行结束、崩溃或内存耗尽，
  下次启动会提示「上次没有正常退出」；内存耗尽会在 logs 里留一份诊断报告，每 30 分钟记一行内存占用
- 日志更全：朗读版什么时候写好、推送首句合成用了多久、设备通知后多久来取、兜底摘要用的模型 / 用时 / 失败原因（超时写明白）

## 1.0.0-rc.35

- **修复压缩偶尔把一整段对话丢掉**：摘要模型有时把「要记住的事」写在最前、摘要正文为空，以前会被当成失败，这段对话只剩你说过的十几句原话，她说过的、你们定下的约定都没了。
  现在不管先写哪个都能认出来；只写了要记住的几条就拿它们当摘要；什么都没写会再要一次
- **模型一个字没说就结束时自动重试**：以前直接回一条空的、还记进历史；现在不记，必要时先压缩一下再试一次，连着两次都空才提示你

## 1.0.0-rc.34

- **USER / AGENTS / TOOLS 全家共用一份**：关于你的信息、全家的规矩、这台电脑的环境写一次就够，她记下的关于你的事其他 agent 也知道。
  每个 agent 自己的同名文件只写补充（叠加在后面）；SOUL、IDENTITY、HEARTBEAT、长期记忆仍然各自一份。
  升级后现有的文件原样当作补充，内容不变；「Agents → 人设文件」里能「挪进共享」
- **恢复默认**：人设文件每个都能「恢复默认」或「所有 agent 一起恢复」，原文件先备份到工作目录的 `.persona-backup-时间/`
- **工具怎么用不用再写进 AGENTS.md**：待办、传话、子任务、记忆怎么分、定时任务这些「什么时候用哪个」，系统按她手上的工具自动告诉她，以后加新功能也自动跟上

## 1.0.0-rc.33

- **Agent 之间传话不再进对方的主对话**：以前别的 agent 找她，消息直接进她和你聊天的那个会话——你们的聊天里混进别人的话、每次都背着整段主对话（费 token）、
  她和别的 agent 说话时你找她还要排队。现在一次交互一个单独的会话：这一次里来回几次接得上，下一次再找就是新会话；会话页「后台」里能看到
- **她不再什么都往 USER.md 写**：USER.md 只放你本人的稳定信息（称呼、家人、作息、口味、习惯喜好），其它默认记进长期记忆（聊到相关话题会自动想起）。
  之前写错进 USER.md 的不会自动挪走，可以在「Agents → 人设文件」里整理，或让她自己把「自动记录」里不是你个人信息的挪到长期记忆

## 1.0.0-rc.31

## 1.0.0-rc.28

- **待办不再「报了完成其实没做完」**：最后必须写明状态（完成 / 没做完 / 需要主人），没写或输出被截断会接着催；没做完的照实汇报，管理界面可「继续做」或「重新开始」

| Linux（Debian / Ubuntu） | `kagura_*_amd64.deb` | `sudo apt install ./kagura_*.deb`，然后 `systemctl --user enable --now kagura` |
| Linux（其它发行版） | `Kagura-*-x86_64.AppImage` | `chmod +x` 后双击或在终端运行 |
| CoreS3 设备固件 | `kagura-device-*.zip` | 按包里的「烧录说明.md」上传到设备 |

`SHA256SUMS` 是校验和。安装包暂未签名，Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」。

## 第一次用

1. 装好后打开 **http://127.0.0.1:5000/admin**（只限本机），在「设置 → 首次设置」填你自己的模型服务商、模型名和 API Key（不预设任何模型），再填百度语音 Key。
2. 设备开机后会在局域网自动找到服务端。
3. 从旧版迁移：`kagura migrate <voice_server.py 所在目录>`；从 OpenClaw 迁移：管理界面「定时任务 → 从 OpenClaw 导入」。
4. 旧的 mosquitto 要停掉：新服务端自带 MQTT（端口 1883）。

数据在 `%APPDATA%\Kagura`（Windows）或 `~/.local/share/kagura`（Linux），卸载不会删除。
