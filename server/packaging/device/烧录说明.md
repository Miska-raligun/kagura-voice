# Kagura 设备固件（M5Stack CoreS3）烧录说明

压缩包里的目录结构就是设备 flash 上的结构：

```
flash/main.py                 → /flash/main.py（开机引导，三行）
flash/kagura/src/*.py         → /flash/kagura/src/
flash/kagura/resource/        → /flash/kagura/resource/（背景图等，可选）
```

## 第一次烧录

1. 用 **M5Burner** 给 CoreS3 烧 **UIFlow2** 固件（WiFi 可以先不配，设备屏幕上能配网）。
2. 浏览器打开 **uiflow2.m5stack.com**，连上设备，左侧 **webterminal → File** 打开文件管理。
3. 新建目录 `/flash/kagura/src`，把 `flash/kagura/src/` 里的全部 `.py` 上传进去。
4. 把 `flash/main.py` 上传为 `/flash/main.py`。
5. 可选：新建 `/flash/kagura/resource`，上传背景图（建议 320×240 的 JPG，单个文件别超过约 100KB）。
6. 重启设备。屏幕上选 WiFi、输密码；之后设备会在局域网里自动找到服务端（不用填 IP）。

## 升级

只需要重新上传 `/flash/kagura/src/` 下的 `.py`（覆盖同名文件），重启即可。设置与配网信息在
`/flash/kagura/data/`，不受影响。

## 和服务端的配合

- 服务端版本与固件版本一起发布；新服务端也兼容老固件（老固件没有「边生成边播」）。
- 服务端在 Windows 上要放行防火墙（安装包会自动加规则）；Linux 放行 TCP 5000/1883/5002、UDP 5001。
- 设备连不上时，先在服务端管理界面「设备」页看有没有心跳、看日志；录音效果在那里能直接试听。
