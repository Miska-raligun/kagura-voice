Kagura 语音服务端 —— 使用说明
================================

1. 启动
   开始菜单「Kagura 服务端」。启动后不会占着控制台窗口：右下角托盘会出现 Kagura 图标，
   右键可以「打开管理页面 / 打开日志文件夹 / 重启服务端 / 退出」，双击图标直接打开管理界面。
   第一次启动会弹一个托盘提示，点一下或右键打开管理界面：
       http://127.0.0.1:5000/admin
   在「设置 → 首次设置」里填一个模型服务商（接口地址、模型名、API Key），再到「语音与设备」填百度语音的 Key。
   管理界面只能在这台电脑上打开，局域网其它设备访问会被拒绝。

2. 让设备连上来
   设备（CoreS3）开机会在局域网里自动找服务端（UDP 5001），不用填 IP。
   连不上时检查：
   - 安装时勾选了「允许局域网里的设备连接」（Windows 防火墙规则名 Kagura）；
   - 设备和电脑在同一个 WiFi / 局域网；
   - 没有别的程序占用 5000/1883/5002 端口：Kagura 启动时会自己检查，被占了会在窗口里
     告诉你是谁（旧的 WSL 端口转发、mosquitto 等），选一下就帮你腾出来。
   - 双击「Kagura 服务端」提示「已经在运行了」：开机自启的那个在后台，回车打开管理界面即可。

3. 数据在哪
   %APPDATA%\Kagura —— 配置 config.json、agent 人设与记忆（agents\）、对话、定时任务、渠道配置都在这里。
   日志在 %APPDATA%\Kagura\logs\kagura.log（超过 5MB 自动滚成 kagura.1.log，最多留 3 份）。
   备份就拷这个目录。卸载不会删除它。

4. 从旧版迁移
   - 旧的 Python 服务端：在命令行运行
       "C:\Program Files\Kagura\kagura.exe" migrate D:\kagura-voice
     （参数是 voice_server.py 所在目录；会迁移 config.py、提醒、定时拍照、快照、语音缓存）
   - OpenClaw：管理界面「定时任务 → 从 OpenClaw 导入」，或命令行 kagura.exe import-openclaw

5. 开机自启
   安装时勾选「开机自动启动」会在启动文件夹放一个最小化运行的快捷方式。
   不想要了：Win+R 输入 shell:startup，删掉里面的 Kagura。

6. 杀毒软件 / SmartScreen 提示
   安装包暂时没有代码签名，Windows 可能提示「未知发布者」：点「更多信息 → 仍要运行」。
